# Changelog

## 0.3.0

- Large hover cards with registration, aircraft model/type and available flight/database details
- Linked aircraft-row, icon and trail highlighting
- Click/tap details for touchscreens
- Configurable fixed starting zoom and automatic-fit zoom offset
- Larger portrait fullscreen aircraft-list text

## 0.2.0

- Portrait and landscape fullscreen arrangements
- Landscape information panel on either side
- Fullscreen resizing support

## 0.1.0

- Nearby aircraft and helicopter map using the adsb.fi public feed
- Flight trails, position ages, stale-report handling and helicopter filtering
- Compact portrait layout, local Leaflet assets and a standalone preview
- OpenStreetMap background tiles styled dark in the browser
